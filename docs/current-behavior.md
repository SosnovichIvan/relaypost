# Что доступно и что осталось

Состояние production: версия 0.1.0, выпуск 2026-10-20. Прошли 152 теста,
production pipeline, проверка прокси и успешный getUpdates. Это подтверждает
работу управляющего бота и сети, но не реальную публикацию в каждую соцсеть.
Поддержка ниже реализована в feature/support и до отдельного выпуска недоступна.

## Доступно пользователю

| Действие | Текущий сценарий |
| --- | --- |
| Начать работу | `/start`, инструкции в личке |
| Несколько подключений | `/connect telegram|max|vk ТОКЕН`, список `/accounts`; данные разделены между пользователями |
| Telegram | Отдельные боты публикуют в каналы/группы с выданными правами; личный аккаунт через код входа не подключается |
| MAX | Bot API: сообщения, фото, видео в доступные чаты/каналы; личный аккаунт через код входа не подключается |
| ВК | User access token: стена пользователя/сообщества, фото и обычное видео при наличии разрешений |
| Выбор назначения | `/add`, `/targets`; `/discover ID` проверяет до 20 площадок MAX/ВК и личную стену ВК |
| Истории | Telegram Business с правом управления историями; `/addstory` для ВК при доступе API; истории MAX не предлагаются |
| Публикация | Отправить текст, одно фото или видео; бот предложит кнопки по подключениям, правам и формату; каждое место подтверждается отдельно |
| Контроль | `/status`: результаты и неопределённые доставки; `/disconnect ID`: удалить подключение |

Медиа — до 20 МБ. Публикация сразу во все назначения одной кнопкой, альбомы,
редактор, расписание и полноценный календарь пока отсутствуют. Видео ВК — не Клипы.
Токены вводятся в Telegram и удаляются ботом перед проверкой; это не OAuth-вход.

## Ближайший выпуск: поддержка

`/support`, `/start support` или `/support текст`; ответ на приглашение бота
создаёт обращение. Владелец отвечает на карточку, пользователь получает ответ
от имени RelayPost. Команда есть в меню и `/start`. Нужен настроенный получатель
SUPPORT_CHAT_ID; пока он не задан, обращения не принимаются. См. [support.md](support.md).
